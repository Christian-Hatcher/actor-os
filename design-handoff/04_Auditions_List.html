Default agenda. Grouped by day. Today highlighted amber. Status chip + pay on the right. Awaiting-reply auditions cluster at the bottom with em-dashes for time. Tap any row to open the audition detail.

Agenda rules

  • Day groups sort chronologically; "Awaiting reply" sits last.
  • Today day-header gets an amber dot + label color.
  • In-progress / upcoming-soon row gets the amber left stripe.
  • Pay color codes: green = booked, paper = pending callback, dim = awaiting reply.
View toggle
  • Top-right pair of icons cycles Agenda ⇄ Calendar.
  • Selection persists per device.
Filters
  • One chip = one status. All default selected.
  • Counts update live as data refreshes.
  • Multi-select supported (long-press to add).

Month grid. Dots indicate the day's status mix — amber callback, blue submission/self-tape due, green booked shoot. Today is inverted (paper bg). Tap a day → selected-day events slide in below.

Calendar rules

  • Up to 3 dots per day. Beyond that, summarized as a single dot with count badge.
  • Today = inverted paper background.
